Как сохраняются изменения
Черновик хранится только в этом браузере. Для обновления сайта скачайте content.js и замените им одноимённый файл сайта. Редактор не меняет опубликованный сайт напрямую.
Как обновить сайт на GitHub Pages

Откройте репозиторий сайта на GitHub → Add file → Upload files. Перетащите скачанный content.js в корень сайта, заменив прежний файл, и нажмите Commit changes. Через несколько минут изменения появятся на сайте. Для сайта в Sites передайте скачанный файл в этот чат — я опубликую обновление.

Личные настройки этого браузера

Настройка действует только в этом браузере. Сам черновик доступен только вашему аккаунту ChatGPT

Перенести черновик на другое устройство

Скачайте резервную копию и откройте её в редакторе на другом устройстве.
